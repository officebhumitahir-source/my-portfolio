Minimalist Launcher_

Android • Kotlin • Digital Wellbeing

Overview

In an age of constant notification dopamine hits, the Minimalist Launcher is an antidote. It strips away the colorful icons and endless scrolling, replacing them with a purely textual interface.

Designed with the "Function over Friction" philosophy, it helps users reclaim their screen time by adding a conscious friction to opening addictive apps.

Key Features

  • Text-only App Drawer (No Icons).
  • Configurable "Focus Mode" timer.
  • Notification "Batching" to reduce interruptions.
  • Ultra-lightweight (< 2MB size).

TECH STACK

Lang Kotlin
Arch MVVM
UI Jetpack Compose
DB Room SQLite
