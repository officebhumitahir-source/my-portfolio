Shree Durga Textiles_

Web • Luxury Catalog • Inventory Admin

Overview

Designed and built a premium digital storefront and B2B wholesale platform for Shree Durga Textiles, a prominent saree manufacturer and wholesale dealer based in Surat, Gujarat. The platform highlights heritage craftsmanship by showcasing premium collections like Banarasi Katan silks, Kanjivaram brocades, and designer organza sarees.

Adhering to high-performance standards, the site runs entirely on client-side state engines with local storage backups and secure, passcode-protected administrative panels to allow the client to easily export, import, or update their live inventory catalog.

Key Features

  • Dithered retro-luxury UI/UX matching elite textile branding.
  • Dynamic catalog filtration by fabric and weave variety.
  • Fully custom-built passcode-protected catalog editor panel.
  • JSON Import/Export utility for offline database syncing.
  • Automated WhatsApp catalog query direct links.
